כמה לשרוף?

🔒 הצ'אט נשלח לניתוח של Claude (Anthropic) ולא נשמר אצלנו. כדאי לקבל את הסכמת חברי הקבוצה לפני שמעלים.

איך מייצאים צ'אט מ-WhatsApp?

אנדרואיד

  1. פותחים את הקבוצה ← ⋮ (שלוש נקודות)
  2. עוד ← ייצוא צ'אט
  3. בוחרים ללא מדיה
  4. שומרים את הקובץ ומעלים אותו לכאן

אייפון

  1. פותחים את הקבוצה ← לוחצים על שם הקבוצה
  2. גוללים למטה ← ייצוא צ'אט
  3. בוחרים ללא מדיה
  4. שומרים בקבצים ומעלים את קובץ ה-ZIP כמו שהוא

Telegram

  1. Telegram Desktop ← הקבוצה ← ⋮
  2. Export chat history
  3. פורמט: JSON
  4. מעלים את הקובץ ‎result.json‏
