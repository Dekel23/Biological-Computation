איך מייצאים צ'אט מ-WhatsApp?

אנדרואיד

  1. פותחים את הקבוצה ← ⋮ (שלוש נקודות)
  2. עוד ← ייצוא צ'אט
  3. בוחרים ללא מדיה
  4. שומרים את הקובץ ובוחרים אותו כאן

אייפון

  1. פותחים את הקבוצה ← לוחצים על שם הקבוצה
  2. גוללים למטה ← ייצוא צ'אט
  3. בוחרים ללא מדיה ← שמירה בקבצים
  4. בוחרים כאן את קובץ ה-ZIP כמו שהוא

Telegram

  1. Telegram Desktop ← הקבוצה ← ⋮
  2. Export chat history
  3. פורמט: JSON
  4. בוחרים כאן את ‎result.json‏
